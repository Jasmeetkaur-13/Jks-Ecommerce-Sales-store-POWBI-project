# 🛒 JK's Ecommerce Sales Store | Power BI

## 📌 About the Project
An interactive Power BI dashboard designed to analyze e-commerce sales performance, profit, product categories, payment methods, customer purchases, and state-wise sales.

## 🎯 Key Features
- Total sales, profit, quantity, and average order value (AOV)
- Monthly profit analysis
- Profit by product sub-category
- Sales by customer and state
- Quantity distribution by payment mode
- Category-wise quantity analysis
- Interactive quarterly filters

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 💡 Objective
To identify sales trends, profitable product categories, customer purchasing patterns, and regional performance through interactive dashboards.
